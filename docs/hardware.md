# 硬件连接

## 通用接口要求

运行时通过 Linux 设备接口访问硬件，不依赖特定主控板 SDK。

| 设备 | 接口 | 要求 |
| --- | --- | --- |
| 舵机总线 | 串口 | SCS 协议、单线半双工，默认 1,000,000 baud |
| IMU | I2C | QMI8658，使用 Linux `/dev/i2c-*` 设备接口 |
| 动力电源 | 外部供电 | 满足所用舵机的电压与峰值电流要求，并与控制侧共地 |
| 控制网络 | HTTP | 仅可信网络或本机访问 |

舵机 ID 按运行时顺序配置为：

```text
10 11 12 13 14 20 21 22 23 24 30 31 32 33 34
```

配置需同时匹配机器人机械结构、电机方向与模型。仅修改串口路径不能适配不同关节布局的机器人。

## 通用 Linux PC / 工控机

### 舵机

使用兼容舵机电气接口的 USB 单线半双工适配器。以实际设备路径传入 `--servo-device`，不要仅凭插入顺序假定设备总是 `/dev/ttyUSB0`。

普通 USB 转 TTL 双线串口不能视为单线半双工舵机适配器的直接替代。接线、电平和方向控制以主机、适配器及舵机资料为准。

### IMU

主机必须提供可供 `smbus2` 使用的 Linux I2C 设备接口。外接桥接器仅有厂商自定义 USB 协议时，不能直接作为当前 I2C 后端使用；应先确认驱动是否暴露 `/dev/i2c-*`。

主机缺少可用 I2C 接口时，可用于离线测试，但不能据此认定已具备完整实机运行条件。

## Linux 单板计算机

### 舵机

可以使用 USB 半双工适配器，也可通过板载 UART 连接适配电路。使用板载 UART 前需：

1. 按板卡文档启用接口并确认引脚复用。
2. 确认该串口未被系统控制台或其他服务占用。
3. 核对 TX/RX、电平、接地及半双工转换电路。
4. 将实际串口路径传入 `--servo-device`。

### IMU

按板卡和 QMI8658 模块资料连接 SDA、SCL、供电及地，核对供电电压、逻辑电平和上拉配置。启用系统 I2C 驱动后，将设备节点对应的总线编号传入 `--i2c-bus`。

不同板卡即使使用相同形状的排针，也不能假设引脚功能、总线编号或电气限制相同。

## D-Robotics RDK X3

RDK X3 是可按 Linux 接口配置的部署平台之一，不是项目的运行前提。

- 舵机可使用 USB 半双工适配器；使用板载 UART 时，应按板卡版本和系统镜像核对接口启用方式、引脚及设备节点。
- QMI8658 可连接已启用的板载 I2C 接口；实际总线编号以系统暴露的 `/dev/i2c-*` 为准。
- 排针编号、UART 复用、串口控制台和 I2C 配置须依据所用板卡资料确认，不将其他平台或镜像的接线直接套用。

## 方向控制

默认不启用 RTS 方向控制，适用于能够自行处理方向切换的适配器。只有适配器、驱动与接线均支持相应方式时，才使用 `--servo-rs485`。

该参数用于请求串口方向控制，不表示可以将 SCS 单线总线直接接到任意 RS-485 接口。

## 上电检查

1. 断电检查极性、共地、逻辑电平和半双工接线。
2. 为舵机提供符合规格的独立动力电源，不从主控信号引脚给舵机供电。
3. 固定机器人，确保动作范围内无人和障碍物，并准备切断动力电源。
4. 检查串口与 I2C 设备节点及访问权限。
5. 以 `shadow` 模式启动，检查全部舵机反馈与 IMU。
6. 完成 `validation.md` 中的标定与安全检查后，再使能运动。
