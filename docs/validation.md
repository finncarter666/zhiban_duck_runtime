# 测试与验收

## 离线测试

在仓库根目录安装统一依赖并执行：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m black --check main.py zhiban_runtime tests tools
```

测试不访问真实串口或 I2C。发布验收应使用完整依赖环境，并确认测试没有因缺少依赖而跳过。

| 范围 | 检查内容 |
| --- | --- |
| 代码约束 | 可执行结构、名称映射和 Python 语法兼容性 |
| 模型完整性 | 模型文件与数值载荷的 SHA-256 |
| 模型推理 | 固定 61 维输入下的五个模型输出，CPU float32 绝对误差不超过 `1e-5` |
| 数值处理 | 观测顺序、单位、动作历史、滤波和嘴部裁剪 |
| 姿态恢复 | 无效反馈、阈值、计数和阶段保持时间 |
| 消息与硬件 | 报文校验、命令时效、显式重新使能和卸力 |
| 实时性 | 增量收帧、超时、固定周期调度、漏周期统计和诊断字段 |
| Web 与 CLI | 静态资源、控制节点、路由、参数与跨工作目录启动 |
| 发布资料 | 文档引用、统一依赖与平台展示名称 |

## 测试基线

测试夹具位于 `tests/fixtures/`，包括执行结构约束、名称映射、明确的时序与校准保持行为版本及固定推理结果。模型文件校验值位于 `models/manifest.json`。

可执行结构比较忽略注释、docstring、排版和模块顶层导入，仅按测试中列出的标识符及展示文字映射进行规范化。计算常量、操作顺序、控制分支和调用结构纳入比较；资源定位和接口接线由集成测试覆盖。

基线用于检测意外变化，不能替代行为测试。算法、模型或调度行为变化时，需要明确变更范围和独立验证依据，不能只通过更新指纹或期望输出来消除测试失败。

Python 语法检查不证明所有依赖均可在相应版本或架构上运行。应在目标 Linux 系统、Python 版本和 CPU 架构下完成安装与测试。

## 浏览器验收

分别使用桌面浏览器与手机检查总览、舵机设置和标零页面：

1. 导航和资源正常加载，无横向溢出，控制台无未处理的 JavaScript 异常。
2. 状态来自接口实际反馈；断线时不继续显示有效读数，重新连接后恢复更新。
3. 模式切换、键盘、触摸摇杆、头部和嘴部调节发送预期请求。
4. 卸力按钮保持可访问，停止运动与卸力的含义清晰。
5. 标零自动进入、单关节操作、进度和退出符合设备状态。
6. 舵机扫描、停止、选择 ID、读取和维护结果正确显示。
7. 页面隐藏、关闭及网络中断后的心跳和退出行为符合运行约定。

可使用本机 Chrome 或 Chromium 执行模拟 API 浏览器回归：

```bash
python tests/browser/check_web_interface.py
# Chromium 可通过 CHROME_BINARY 环境变量指定可执行文件。
```

脚本不访问硬件，检查状态布局与表格节点稳定性、断线恢复、触摸滚动防误触、滑块横向调节、摇杆解锁及释放归零，并保存截图到临时目录。

模拟 API 适用于验证页面和请求结构，不能证明真实设备执行成功。涉及扭矩、标零或持久化写入的验收须先落实安全措施。

## 实机验收

1. 按 `hardware.md` 核对接线、供电、电平和设备权限；固定或悬空机器人，准备切断动力电源。
2. 使用 `shadow` 启动，确认 15 个舵机 ID 在线、IMU 有效、模型加载成功。
3. 确认关节顺序、电机方向、默认姿态与 IMU 安装方向。比较录制反馈对应的观测、原始动作、滤波动作和最终目标。
4. 进入 `hold`，确认首次使能目标来自实测角度。
5. 使用小幅度命令测试行走与头部动作，逐项检查 Roller、Pick、Roulade 和姿态恢复。
6. 按 `realtime.md` 在正常推理与 Web 负载下检查频率、漏周期、P99 和最大耗时。
7. 分别验证浏览器心跳丢失、硬件命令超时、IMU 无效及舵机缺失的行为。浏览器无操作通常只清零运动；命令超时后须显式重新使能。
8. 在标零页逐个核对保持目标 `2048` 与扭矩使能读回，以及实际关节保持；未选关节应维持卸力，退出标零应全部卸力。
9. 验证卸力、标零/维护进入与退出、服务心跳超时和进程停止后的实际扭矩状态。
10. 完成上述检查后再进行落地测试。

## 验收记录

每次设备验收应记录软件版本、Linux 镜像、Python 和依赖版本、CPU 架构、串口适配器、设备参数、模型校验值、测试负载及结果。性能记录至少包含实测频率、周期和工作耗时的 P99/max、漏周期增量。

离线测试和界面验证不能证明供电、总线电气、舵机保护、实时调度或机械安全。没有目标设备的验收记录时，不应将其标记为已验证平台。
