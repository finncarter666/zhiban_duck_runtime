# Web 工作台

工作台使用本地 HTML、CSS、JavaScript 和 SVG，无需前端构建步骤、外部字体或 CDN。页面采用浅色导航栏、绿色强调色和卡片布局，适配桌面与手机。共享脚本 `assets/web/studio.js` 只负责展示，复用各页面的状态轮询，不发送控制命令。

## 功能入口

| 功能 | 路径 | 内容 |
| --- | --- | --- |
| 实时状态 | `/` | 连接与模式、反馈/推理频率、在线舵机、IMU、恢复状态和关节反馈 |
| 舵机控制 | `/#motion` | 模式选择、双摇杆、键盘操作、头部与嘴部调节；卸力按钮固定在顶部 |
| 舵机设置 | `/servo.html` | 扫描与选择 ID、设置中位、参数读写，以及保护配置 |
| 鸭子标零 | `/calibrate.html` | 逐关节标零与保持、完成进度、退出标零 |

## 数据显示边界

- 展示范围为控制模式、频率、关节反馈、IMU 和恢复状态，不包含电池、温度或摄像头遥测。
- 鸭子图为静态结构示意，明确标注“结构示意 · 非实时姿态”，不表示模型可视化或实际关节姿态。
- 服务可连接不等于硬件反馈正常；界面区分正常连接、反馈异常与连接中断。请求失败时清除总览旧读数，避免将缓存状态误认为实时状态。
- 舵机维护中的保护配置属于参数写入功能，不是温度、电池等传感器监测。广播成功只表示命令已发送，不表示每台舵机均已确认执行。

## 操作约定

- 打开鸭子标零页会自动进入标零并卸力；进入前固定机器人、确认机械安全。
- 设置中位及修改 ID 前按页面提示确认接线与目标，避免误写其他舵机。
- 停止运动指令不等于关闭扭矩；需要卸力时使用顶部卸力按钮，并确认实际设备状态。
- 断线提示是界面反馈，不替代硬件看门狗或物理断电手段。没有连接真实设备的页面测试不能证明机械安全。

验证范围参见 `validation.md`。

## 阅读与触屏操作

- 参数、操作按钮和提示使用不小于 14 px 的字体；浅色卡片使用深色文字，深色横幅使用浅色文字。
- 模式、连接、诊断和读数区域预留固定高度。超长文本可在区域内滚动查看，实时反馈表原位更新数值，不因轮询重建行或改变列宽。
- 手机默认将摇杆区域用于页面滚动。点击“启用一次摇杆触控”后可拖动摇杆；释放、取消或离开页面后重新锁定。鼠标和键盘操作不需要触控解锁。
- 触摸滑块时，纵向滑动用于滚动页面，明确的横向拖动才调整数值。单次轻触不跳转参数；键盘方向键和鼠标仍可直接调节。

## 单关节中位保持

进入标零后所有关节卸力。手动对齐目标关节并点击“设为中位并保持”，运行时检查该 ID 的应答，重置中位，写入编码器目标 `2048`，再单独使能该关节扭矩。目标位置与扭矩寄存器读回匹配后，界面显示“保持 2048”。其他未标零关节不会因此使能。

通信失败或读回不匹配时不计入完成数，并尝试卸力当前关节；其他已确认的保持关节不受影响。退出标零会卸力全部关节。寄存器确认不等同于机械保持力验证，仍需检查供电、舵机保护状态及负载；不能仅凭界面状态判断硬件安全。
